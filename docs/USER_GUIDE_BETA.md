# 家庭回忆相册 · 安装和使用教程（Beta 0.5）

> 面向完全不懂技术的用户。跟着截图位置一步步点，10 分钟装好。
> 两个版本选一个装：**Mac 版**（装在自己的苹果电脑上）或 **NAS 版**（装在群晖等 NAS 上，全家都能访问）。

---

# 第一部分 · Mac 版

## 1. 下载与安装

1. 从下载链接获得 `FamilyMemoryAlbum-Beta-0.5.dmg`（约 1.5G），双击打开它
2. 弹出的窗口里有一个 **FamilyMemoryAlbum.app** 图标，把它 **拖进旁边的「应用程序」文件夹**
3. 拖完后，DMG 窗口可以关闭；在「应用程序」里找到 **FamilyMemoryAlbum**

## 2. 第一次打开（重要，别跳过）

因为这个软件还没有花钱买苹果的签名认证，第一次打开会提示「无法验证开发者」：

1. 在「应用程序」里**右键点击** FamilyMemoryAlbum → 选 **「打开」**
2. 弹窗里再点一次 **「打开」** —— 只需要做这一次，以后双击就能正常打开
3. 如果还是被拦：打开 **系统设置 → 隐私与安全性**，往下滚到安全提示处，点 **「仍要打开」**

## 3. 首启向导（3 步）

打开后会自动弹出浏览器进入欢迎页：

1. **创建管理员账号**：填用户名和密码（这是管理全家相册的账号，密码记牢）
2. **选择照片目录**：点「浏览」，选中你放照片的文件夹（比如「照片」文件夹、外接硬盘目录）
3. **开始扫描**：点开始后程序会逐张读取照片（时间、地点、人脸识别），进度条会实时走
   - 1 万张照片大约 20-40 分钟；期间可以最小化窗口干别的，**不用盯着**

## 4. 日常使用

以后双击 FamilyMemoryAlbum 就行——它会启动服务并自动打开浏览器进入登录页。
**登录**后你会看到照片墙。功能地图：

| 功能 | 在哪 | 怎么用 |
|---|---|---|
| **照片墙** | 首页 | 滚轮/拖动翻看每日照片，右侧是分类入口 |
| **时间线** | 首页顶部日期 | 按天/月/年回看；点年份直接跳到那一年 |
| **地点** | 侧栏「地点」 | 按城市/景点聚合；点地图上的圆点看当地照片 |
| **人物** | 侧栏「人物」 | 每个人一个相册；可合并重复的人、改名字、设关系（如"女儿"） |
| **场景** | 侧栏「场景」 | 旅行/美食/儿童/花草等自动分类 |
| **搜索** | 首页对话输入框 | 直接打字问："2025 年春节的照片""有妈妈的旅行照" |
| **旅行标记** | 地图页 | 勾选一段日期生成"旅行卡片"，首页按行程回看 |
| **相似照片** | 侧栏「相似」 | 连拍/重复照自动分组，选一张最佳，其余可一键清理 |
| **隐私相册** | 侧栏「隐私」 | 设 4-12 位数字 PIN，把私密照片移进去；浏览需输 PIN |
| **设置** | 右上角 ⚙ | 管理照片来源目录、模型任务、家人账号 |

## 5. 常见问题（Mac 版）

**Q：打开提示"已损坏，无法打开"？**
系统认为从网上下载的文件不可信。执行：系统设置 → 隐私与安全性 → 「仍要打开」；或终端执行
`sudo xattr -rd com.apple.quarantine /Applications/FamilyMemoryAlbum.app`

**Q：扫描很慢 / 风扇响？**
人脸识别是最耗性能的一步，只在首次扫描发生。扫完日常浏览非常轻快。

**Q：照片存哪了？会不会被我移动？**
**原片永远在你原来的文件夹里，软件不移动、不复制、不上传。** 它只建自己的数据库和缩略图（在 `~/Library/Application Support/FamilyMemoryAlbum`）。

**Q：怎么加新的照片文件夹？**
设置 → 来源管理 → 添加目录 → 重新扫描即可。

**Q：怎么升级？**
下载新 DMG 覆盖拖入「应用程序」即可，数据全部保留。

**Q：卸载会丢照片吗？**
不会。删除 App 只删程序；你的照片原片和数据目录都在原处。

# 第二部分 · NAS 版

## 1. 安装前确认

- 你的 NAS 是 **Intel/AMD 芯片**（群晖大部分型号是），内存 4G 起步、推荐 8G
- 群晖用户：套件中心装好 **Container Manager**（DS 7.0-7.1 叫 Docker）
- 下载部署包：`FamilyMemoryAlbum-NAS-Beta-0.5.tar.gz`（约 441M）

## 2. 方式 A：一键部署（推荐，2 条命令）

1. 用群晖 **File Station** 把部署包上传到 NAS（如 `/homes/你的用户名/`）
2. 控制面板 → 终端机和 SNMP → 勾选「启用 SSH」；电脑上用终端连接：
   `ssh 你的NAS用户名@NAS的IP`
3. 执行：

```bash
cd /volume1/homes/你的用户名
./install_nas.sh --image FamilyMemoryAlbum-NAS-Beta-0.5.tar.gz \
                 --dir /volume1/docker/family-memory-album \
                 --photos /volume1/photos
```

> - `--dir` 是安装目录（数据库存这里）；`--photos` 改成你 NAS 上放照片的共享文件夹
> - 提示权限不够就在前面加 `sudo `
> - 脚本跑完会打印 **访问地址**（形如 `http://192.168.x.x:8788`）

## 3. 方式 B：纯图形界面（不碰命令行）

详细图文见 `docs/INSTALL_NAS.md` 第二节（Container Manager 导入映像 + 粘贴 compose 模板）。

## 4. 首次使用（和 Mac 版一样的 3 步向导）

浏览器打开 `http://NAS的IP:8788` → 创建管理员 → 照片目录填 **`/photos`** → 开始扫描。

全家设备（手机/平板/电视）同一 WiFi 下打开这个地址都能看；电视大屏模式访问 `http://NAS的IP:8788/tv.html`。

## 5. 常见问题（NAS 版）

**Q：浏览器打不开？**
Container Manager 里看容器是否「运行中」；SSH 执行 `docker logs family-memory-album` 看报错；确认 8788 端口没被防火墙拦。

**Q：扫描完照片是空的？**
检查配置里 `/photos` 对应的宿主路径是否真的是你放照片的文件夹。

**Q：怎么升级？**
下载新版部署包，重跑一遍安装命令（同一个 `--dir`），数据自动保留。

**Q：数据会不会丢？**
数据库和缩略图在安装目录的 `data/` 里，照片原片不动。升级只换程序；卸载容器不删目录就不丢数据。建议定期用群晖 Hyper Backup 备份 `data/` 目录。

**Q：外网能访问吗？**
默认仅局域网。建议用群晖自带 VPN / Tailscale 出门访问，不建议直接开放公网端口。

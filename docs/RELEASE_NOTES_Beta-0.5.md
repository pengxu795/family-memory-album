# 家庭回忆相册 · 版本说明（Beta 0.5）

发布日期：2026-09-10

---

## 一、这个版本是什么

「家庭回忆相册」的第一个公开 Beta 测试版：把散落在各处的家庭照片变成
**会自己整理的相册**——时间线、地点、人物、场景全自动归好类，用一句话
就能搜照片，人脸识别、隐私相册、旅行卡片一应俱全。所有识别在你的设备
本地完成，照片不上传任何云端。

| 分发物 | 文件名 | 大小 | 内部版本 |
|---|---|---|---|
| Mac 版 | `FamilyMemoryAlbum-Beta-0.5.dmg` | 1.5G | App 0.4.2 |
| NAS 版 | `FamilyMemoryAlbum-NAS-Beta-0.5.tar.gz` | 441M | 镜像 0.5（含一键部署脚本） |
| 教程 | `家庭回忆相册-安装和使用教程-Beta0.5.md` / `.pdf` | — | 与本说明同目录 |

安装步骤请看《家庭回忆相册 · 安装和使用教程（Beta 0.5）》。

## 二、功能清单（Beta 0.5）

- **照片墙与时间线**：按天浏览，年份一键跳转，1600+ 天日签标题
- **自动分类**：地点（地图打点）/ 人物（人脸识别聚类）/ 场景（旅行、美食、儿童…）
- **对话式搜索**：输入"2025 年春节的照片"直接出结果；本地+云端大模型混合
- **旅行卡片**：勾选日期自动生成行程相册
- **相似照片**：连拍/重复自动分组，一键留最佳
- **隐私相册**：数字 PIN 保护，私密照片独立入口
- **人脸全链路**：识别、性别年龄、表情、精确裁剪（ffmpeg 9.0.1 精确像素裁切）
- **视频支持**：封面抽帧、在线播放（Range 流式）
- **EXIF 转正**：iPhone/华为 HEIC/JPG 方向自动摆正
- **多用户**：管理员 + 家人/访客账号，权限分级
- **双端**：Mac 原生安装包 / NAS Docker 一键部署（群晖 Container Manager 图形安装也支持）

## 三、已知限制（Beta）

1. **人脸首扫需要时间**：1 万张照片的人脸识别约 1-2 小时（NAS 低配更久），
   期间 NAS/电脑风扇会比较响，扫完即恢复安静；识别在后台进行，不影响浏览。
2. **Mac 版未购买苹果签名**：首次打开需「右键 → 打开」放行一次（教程有图文）；
   后续版本视用户量决定是否上签名（99 美元/年）。
3. **语义搜索（AI 向量找图）默认关闭**：需 8G 内存设备并手动下载 1.4G 模型
   （教程"可选增强"一节）；标签式文字搜索不受影响，所有设备可用。
4. **NAS 仅支持 x86 架构**（Intel/AMD 芯片机型）；ARM 架构 NAS 暂不支持。

## 四、数据安全说明

- 照片原片永远在原位置，软件不移动、不复制、不上传
- 识别与索引全部本地完成；仅"对话搜索"的语义理解部分可选调用云端大模型，
  调用时只发送文字描述统计，不发送照片
- 建议对 NAS 数据目录做定期备份（Hyper Backup 等）

## 五、反馈渠道（建议）

- Beta 阶段建议使用腾讯文档/飞书表格收集：一个"问题反馈"表单（现象+截图+机型）
- 严重问题（装不上/闪退/丢数据）请标注【P0】，我们优先处理
- 交流群入口可在此处补充二维码
